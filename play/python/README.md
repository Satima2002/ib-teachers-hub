# Python шаг за шагом с Оркеном

Открытый курс Python для 6–7 классов. Работает без сервера: обычные HTML и JavaScript, код запускается в браузере через [Skulpt](https://skulpt.org).
Встраивается в сайт как тренажёр по [протоколу v1](../../docs/trainer-protocol.md) и может открываться сам по себе.

## Как это устроено

| Файл | Что делает |
|---|---|
| `index.html` | страница курса: карточки модулей, профиль, код прогресса |
| `trainer.html?c=<id>` | тренажёр одного модуля |
| `engine.js` | общий движок: Оркен, запуск Python, проверка шагов, достижения, связь с сайтом |
| `core.js` | чистые функции проверки (работают и в Node, для тестов) |
| `courses/*.js` | **модули** с уровнями и шагами; `registry.js` задаёт порядок |
| `progress.js` | сохранение прогресса и «код прогресса» |
| `teacher.html` | таблица по кодам прогресса учеников |
| `poses.js`, `style.css` | картинки Оркена и стили |
| `tests/validate.js` | проверка всех шагов: решение проходит, заготовка нет |

## Результаты учеников

- По умолчанию всё хранится только в браузере ученика.
- Если ученик включит «📤 Учителю», каждый пройденный шаг отправляется на сайт (`trainer:result`, `lesson` = `модуль/шаг`, например `basics/1-3`). Оценка из 3: 3 — сам, 2 — с подсказкой или одной ошибкой, 1 — нужна была помощь. Код ученика не отправляется. Имя берётся из поля над тренажёром на сайте.
- Без сайта: ученик копирует **код прогресса** на странице курса и присылает учителю, а учитель вставляет коды в `teacher.html`.
- Храните минимум: имя и класс. Фамилии, почту и пароли в профиль не вносите.

## Как добавить новую тему

1. Скопируйте `courses/loops.js` в `courses/<новое-id>.js`, поменяйте `id`, `title`, `sub`, `icon`, `next`.
2. Опишите уровни и шаги (формат ниже). Номера шагов (`id`) должны быть уникальны во всём курсе.
3. Допишите `<новое-id>` в `COURSE_FILES` в `courses/registry.js`.
4. Запустите `node tests/validate.js` (нужны node и python3), добавьте `<новое-id>` в список `files` в тесте.

### Типы шагов

- `run`: ученик запускает готовую программу (`tests:{ran:true}`) или видит ошибку (`tests:{ranError:true}`).
- `edit`: ученик меняет код. Проверка: `tests:{must:[…], not:[…], count:[…], runs:[{inputs:[…], has:[…]}]}`, примеры в `courses/basics.js`.
- `quiz`: вопрос с вариантами (`options`, `correct`, `why`).
- `parsons`: собрать программу из перемешанных строк (`lines`, `order`, `constraints`).

Правила для заданий: маленький шаг, мгновенная проверка, в заготовках нет бесконечных циклов, ошибки объясняются спокойно, без лидербордов.

## Участие

Присылайте pull request с новым модулем или исправлением. Перед этим запустите `node tests/validate.js`. Хорошие модули: строки, списки, функции, черепашка.
