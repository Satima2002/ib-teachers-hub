# Протокол тренажёров, версия 1

Любой HTML-тренажёр можно встроить в пост, если он соблюдает этот протокол.
Тренажёр **ничего не знает о базе и не хранит ключей**: он только сообщает странице-родителю, что произошло.
Сайт проверяет сообщение и сам записывает результат.

## Где живут тренажёры

- На **отдельном домене**, например `https://teacher-play.vercel.app/ielts/`. Это папка `play` в репозитории, отдельный проект Vercel.
- Сайт встраивает его в `<iframe sandbox="allow-scripts allow-same-origin allow-forms allow-popups">`.
- Почему так безопасно: у тренажёра свой домен, поэтому `allow-same-origin` даёт ему **его собственное** хранилище (прогресс в localStorage), но не доступ к сайту, аккаунтам и ключам.
- Сайт принимает сообщения **только** от своего iframe и только с домена тренажёра (`event.origin` и `event.source` проверяются).

## Сообщения

Тренажёр отправляет их так:

```js
window.parent.postMessage({ v: 1, type: '...', ...данные }, '*');
```

| type | Поля | Когда отправлять |
|---|---|---|
| `trainer:result` | `lesson` (строка до 80 символов), `score` (целое ≥ 0), `max` (целое 1–1000) | Ученик проверил задание или набор вопросов |
| `trainer:finish` | — | Ученик завершил урок или весь тренажёр |
| `trainer:height` | `height` (пиксели) | Необязательно: если тренажёр хочет, чтобы iframe подстроился под его высоту |

Пример:

```js
window.parent.postMessage({ v: 1, type: 'trainer:result', lesson: 'r-tfng/p1', score: 3, max: 4 }, '*');
```

### Что сайт делает сам

- Считает **первую попытку**: первый результат по этому `lesson` из этого браузера. Тренажёру не нужно это отслеживать.
- Добавляет анонимный id браузера и имя, если человек его вписал над тренажёром.
- Ограничивает значения: `score` не больше `max`, длина `lesson` до 80 символов.

## Как назвать `lesson`

Коротко и стабильно: по этому полю строится статистика «самые трудные задания».
Формат `раздел/задание`, например `r-tfng/p1`, `w-t1/check`, `unit2/quiz3`.
Не меняйте названия после публикации, иначе статистика разделится.

## Проверка: тренажёр открыт сам по себе или встроен

```js
const EMBED = (() => { try { return window.parent !== window; } catch (e) { return true; } })();
```

Если не встроен, тренажёр просто работает локально и ничего не отправляет.

## Подсказка для ИИ, чтобы сделать совместимый тренажёр

> Сделай интерактивный HTML-тренажёр одним файлом. Когда ученик проверяет задание, отправляй
> `window.parent.postMessage({v:1, type:'trainer:result', lesson:'<короткий-id-задания>', score:<верно>, max:<всего>}, '*')`.
> Когда ученик завершил весь тренажёр, отправляй `window.parent.postMessage({v:1, type:'trainer:finish'}, '*')`.
> Не используй внешние API и ключи. Прогресс храни в localStorage, оборачивая обращения в try/catch.

## Ограничения

- Балл считается в браузере, поэтому технически его можно подделать. Для обучения это нормально, для оценок нет.
- `'*'` в `postMessage` означает, что результат увидит любая страница, встроившая тренажёр. Это ответы самого ученика, секретов в них нет. Если понадобится, можно ограничить список разрешённых сайтов.
